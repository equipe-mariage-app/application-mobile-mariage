# Qualité et preuves d’évaluation

| Domaine | Preuve à ajouter au fil du projet |
| --- | --- |
| CI et tests | Run GitHub Actions, tests unitaires, tests de widgets et démo Android documentée |
| Architecture et état | PR illustrant les couches et les états de chargement, de résultat et d’erreur |
| Sécurité | Tests de lecture visiteur et de refus d’écriture par un autre propriétaire |
| Internationalisation et accessibilité | Ressources ARB, captures dans les langues retenues, contrôle TalkBack et texte agrandi |
| Agilité | Issues, itérations, contributions et PR relues par les membres |
| Documentation et rendu | README vérifié depuis un clone, journal et scénario de démo |

La matrice complète avec les pages des supports figure dans le [plan de travail](https://github.com/Kemadjou-Cabrel/application-mobile-mariage/blob/main/docs/plan-travail-sallio.md#2-exigences-du-cours-et-preuves-à-préparer).
