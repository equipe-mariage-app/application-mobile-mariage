# Parcours et charte graphique

| Acteur | Parcours |
| --- | --- |
| Visiteur | Explorer → filtrer → ouvrir une fiche → consulter les dates renseignées. |
| Client | Réserver → se connecter ou s’inscrire → reprendre le parcours sur la même salle. |
| Propriétaire | Se connecter → ouvrir Mes salles → publier ou modifier une annonce → renseigner éventuellement les dates. |

Le fichier `sallio_mockups.drawio` est la référence graphique de l’équipe. Utiliser le logo Sallio, le bleu nuit `#0F2942`, l’orange `#FF6B00`, les cartes photo et la navigation basse. Vérifier les contrastes et le grossissement du texte sur les écrans livrés.

La confirmation de réservation et le rôle éventuel du paiement restent à décider.
