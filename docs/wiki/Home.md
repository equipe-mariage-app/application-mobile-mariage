# Sallio

Sallio est une application Flutter pour trouver et réserver une salle événementielle en Belgique. Le catalogue et les disponibilités déclarées sont consultables sans compte. Le visiteur se connecte pour réserver. Le propriétaire utilise son compte pour publier et gérer ses salles sur mobile.
